# Kiểm thử
Các tệp test hiện chỉ có docstring TODO. pytest chưa thu thập được test chức năng. Không xem cú pháp hợp lệ hoặc CI xanh là chức năng đã đạt.
Khi triển khai: dùng CSDL thử riêng, dữ liệu hai gia đình, test quyền và đường lỗi bên cạnh luồng thành công. Không chạy test làm thay đổi dữ liệu trên CSDL thật.
