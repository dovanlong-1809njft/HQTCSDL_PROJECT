# Hướng dẫn sử dụng

Tài liệu hướng dẫn người dùng được bổ sung dần theo từng phân hệ.

- [Cộng đồng & Sự kiện](community-events.md) — bảng tin, bình luận, cảm xúc, báo cáo nội dung, sự kiện, trả lời tham gia, thư viện ảnh và nhắc nhở, trên cả web và app di động.

Các phân hệ còn lại sẽ được bổ sung khi chức năng hoàn thiện. Hiện có thể xem luồng đăng ký, đăng nhập và trang tổng quan trên web.
